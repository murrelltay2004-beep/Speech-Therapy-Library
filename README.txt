SPEECH THERAPY ACTIVITY LIBRARY

Open index.html in a browser to use the library locally.

TO PUBLISH FREE WITH GITHUB PAGES:
1. Create a GitHub account and a new PUBLIC repository (e.g. speech-therapy-library).
2. Upload all files in this folder, including index.html, to the repository root.
3. Go to Settings > Pages > Build and deployment > Deploy from a branch.
4. Select main and /(root), then Save.
5. Wait for GitHub to provide your public website URL. Bookmark it.

IMPORTANT: Public GitHub repositories expose the source files. Never add student names, identifying information, or private notes.
